Changelog

v0.6.0

v0.6.0 — 2026-09-18

Released 2026-09-18 · 41 commits · 12 contributors

  • Durable execution: node results are now persisted before the next node is scheduled.
  • New checkpoint backend interface, with optional TTL on thread checkpoints.
  • Breaking: StateGraph.add_node no longer accepts a bare callable in 0.6.
v0.5.4

v0.5.4 — 2026-09-05

Released 2026-09-05 · 23 commits · 8 contributors

  • Interrupt payloads are validated against the declared schema before surfacing.
  • State snapshots are written incrementally, cutting checkpoint size by ~30%.
v0.5.0

v0.5.0 — 2026-08-21

Released 2026-08-21 · 67 commits · 19 contributors

  • First stable release of the 0.5 line.
  • Node-level retry policies with backoff.
  • Subgraph composition is no longer marked experimental.
v0.4.12

v0.4.12 — 2026-08-07

Released 2026-08-07 · 15 commits · 6 contributors

  • Paginated thread listing.
  • Fixed a race in async streaming when a node raised immediately.
v0.4.9

v0.4.9 — 2026-07-24

Released 2026-07-24 · 29 commits · 11 contributors

  • Time-travel debugging API for replaying a thread from any checkpoint.
  • Store namespaces are isolated per assistant.
